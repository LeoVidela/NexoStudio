# NexoStudio
Página Comercial

## Ver la Página Web

Este sitio está publicado usando GitHub Pages. Para ver la página:

1. La página se publica automáticamente en: `https://leoviedla.github.io/NexoStudio/`
2. Cada vez que se hace push a la rama `main`, la página se actualiza automáticamente

## Configuración de GitHub Pages

GitHub Pages está configurado para desplegarse automáticamente mediante GitHub Actions:

- El workflow se encuentra en `.github/workflows/deploy-pages.yml`
- Se ejecuta automáticamente en cada push a la rama `main`
- También se puede ejecutar manualmente desde la pestaña "Actions" en GitHub

## Estructura del Proyecto

- `index.html` - Página principal del sitio
- `.github/workflows/deploy-pages.yml` - Workflow de despliegue automático
- `README.md` - Este archivo

## Desarrollo Local

Para ver la página localmente, simplemente abre el archivo `index.html` en tu navegador web.
